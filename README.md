# CCNA_Exercise_Labs
Some Cisco Packet Tracer lab exercises to help you pass the CCNA

There are 5 labs in total:
1. ACL & VTY
2. NAT
3. VLANs & ROAS
4. OSPF
5. HSRP & EtherChannel

These are core concepts covered in the CCNA and you should know them from memory.
There are also completed labs for each exercise, so if you get stuck, you can check the configuration of a device there.
